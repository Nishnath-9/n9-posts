# N9 tools
Tenglish-tuned copies of two scripts from github.com/Jakeschincariol/instagram-agent-skill (MIT):
- hookscore_te.py: adds Telugu stakes words (raaledu, kaadu, kani, matrame, miss, loss) and crore/lakh.
- caption_te.py: counts Tenglish asks (pampandi, share cheyyandi, comment lo, save cheskondi).
Run: python3 -I hookscore_te.py hooks.txt  |  python3 -I caption_te.py caption.txt --keywords "IPO allotment,ipo telugu"
